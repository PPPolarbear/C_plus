## 每日文件的六段结构

| 段 | 作用 |

## 四条铁律

1. **验收没全打勾，不进下一天。** 后面的内容建立在前面的正确性上。
2. **卡住超过 40 分钟就跳过。** 标记下来继续走，回头看往往突然就懂了。
3. **不要提前读后面的 Day。** 每天的"读"刚好够用，多读会淹没你。
4. **写不出来就让它先编译通过。** 能跑 > 完美。
