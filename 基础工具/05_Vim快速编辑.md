# 05 · Vim 快速编辑

> **适用**：学过 Vim 但用得少，想能快速编辑而不用鼠标。
> **读 + 练约 1.5 小时。**

---

## 🎯 这一份解决什么问题

**Vim 的价值不是"快"，是"手不离键盘"。**

当你需要在服务器上改配置文件、在终端里快速改几行代码时，Vim 是唯一选择（很多服务器只装了 vi）。

**目标不是变成 Vim 高手，是"能用它干活，不慌"。**

**给你的具体路径**：先在 VS Code 里用 Vim 插件（**投入产出比最高**），熟练后再上真正的 Vim。

## 一、心智模型：模式（**最重要的一节**）

**Vim 卡住人的唯一原因，就是"模式"这个概念。**

```
        ┌─────────────────────────────────┐
        │                                 │
        │   普通模式 (Normal)              │  ← 默认进入这里
        │   —— 按键 = 命令，不是打字        │
        │                                 │
        └───────┬──────────────┬──────────┘
                │              │
          i/a/o │              │ Esc
                ▼              │
        ┌───────────────────────┴─────────┐
        │   插入模式 (Insert)              │
        │   —— 和普通编辑器一样打字         │
        └─────────────────────────────────┘
```

| 模式 | 干什么 | 怎么进出 |
|---|---|---|
| **普通模式** | 移动、删除、复制、粘贴（**按键即命令**） | 按 `Esc` 回到这里 |
| **插入模式** | 打字 | `i` / `a` / `o` 进入 |
| **可视模式** | 选中文本 | `v` 进入 |
| **命令模式** | 保存、退出、替换 | `:` 进入 |

> **在普通模式下敲 `dd` 会删掉一整行；在插入模式下敲 `dd` 就是打了两个字母 d。**
> 这就是为什么新手会觉得"Vim 乱删我的东西"——**多半是忘了自己在哪个模式**。

**习惯：每次操作完按 `Esc`**，让自己回到普通模式。

## 二、生存命令（能活下来）

| 命令 | 作用 |
|---|---|
| `i` | 在光标**前**插入 |
| `a` | 在光标**后**插入（append） |
| `o` | 在**下一行**新开一行并插入 |
| `O` | 在**上一行**新开一行并插入 |
| `Esc` | 回到普通模式 |
| `:w` | 保存 |
| `:q` | 退出 |
| `:wq` 或 `ZZ` | 保存并退出 |
| `:q!` | **不保存强制退出**（搞砸了就用这个） |

## 三、移动（普通模式）

**别用方向键**——手要移到方向键上就失去意义了。

| 命令 | 作用 |
|---|---|
| `h` `j` `k` `l` | ← ↓ ↑ → |
| `w` | 下一个**词**开头 |
| `b` | 上一个词开头 |
| `e` | 当前/下一个词**结尾** |
| `0` | 行首 |
| `^` | 行首（第一个非空字符） |
| `$` | 行尾 |
| `gg` | 文件开头 |
| `G` | 文件结尾 |
| `42G` | 跳到第 42 行 |
| `Ctrl+d` | 向下翻半页 |
| `Ctrl+u` | 向上翻半页 |
| `%` | 跳到匹配的括号 |
| `{` `}` | 上/下一个空行（按段落跳） |

**记忆法**：`h j k l` 里，`j` 像向下的钩子。

## 四、编辑（普通模式）

### 删除

| 命令 | 作用 |
|---|---|
| `x` | 删一个字符 |
| `dd` | **删一整行**（最常用） |
| `dw` | 删一个词 |
| `d$` 或 `D` | 删到行尾 |
| `d0` | 删到行首 |
| `3dd` | 删 3 行 |

### 复制粘贴

| 命令 | 作用 |
|---|---|
| `yy` | **复制一整行** |
| `yw` | 复制一个词 |
| `p` | 粘贴到光标**后** |
| `P` | 粘贴到光标**前** |
| `3yy` | 复制 3 行 |

### 撤销

| 命令 | 作用 |
|---|---|
| `u` | 撤销 |
| `Ctrl+r` | 重做 |

## 五、⭐ 组合规则（Vim 的精髓）

**Vim 不是"几百个命令"，是"操作符 + 动作"的组合。**

```
   操作符  +  动作  =  效果
     d         w        dw  → 删除一个词
     d         $        d$  → 删除到行尾
     d         d        dd  → 删除一行
     y         y        yy  → 复制一行
     c         w        cw  → 修改一个词（删除并进入插入模式）
```

**操作符**：

| 操作符 | 含义 |
|---|---|
| `d` | delete 删除 |
| `y` | yank 复制 |
| `c` | change 修改（删除 + 进入插入模式） |
| `>` | 缩进 |
| `<` | 反缩进 |

**动作**（第三节那些移动命令）：

| 动作 | 含义 |
|---|---|
| `w` | 一个词 |
| `$` | 到行尾 |
| `0` | 到行首 |
| `G` | 到文件末尾 |
| `gg` | 到文件开头 |
| `%` | 到匹配括号 |
| `i` + 对象 | 内部（`di"` = 删引号内的内容） |

**举例，理解这个组合后你能自己造命令**：

| 命令 | 拆解 | 效果 |
|---|---|---|
| `dG` | 删除 + 到文件末尾 | 删到文件末尾 |
| `yG` | 复制 + 到文件末尾 | 复制到文件末尾 |
| `ci"` | 修改 + 引号内部 | **把引号里的内容换掉**（改字符串超好用） |
| `di(` | 删除 + 括号内部 | 删掉括号里的内容 |
| `>G` | 缩进 + 到末尾 | 从当前行缩进到文件末尾 |

**`ci"` 是最高频的一个**：光标在字符串里，敲 `ci"`，引号内的内容被清空并进入插入模式，打完按 `Esc` 就换好了。

## 六、搜索与替换

| 命令 | 作用 |
|---|---|
| `/关键字` | 向下搜索 |
| `?关键字` | 向上搜索 |
| `n` | 下一个匹配 |
| `N` | 上一个匹配 |
| `*` | 搜索光标下的词（快） |
| `:noh` | 取消高亮 |

### 替换

| 命令 | 作用 |
|---|---|
| `:s/old/new/` | 替换**当前行**第一个 |
| `:s/old/new/g` | 替换当前行**全部** |
| `:%s/old/new/g` | 替换**整个文件**（最常用） |
| `:%s/old/new/gc` | 替换整个文件，**每个都问你确认** |

**记忆**：`%` = 整个文件，`g` = global（全部），`c` = confirm（确认）

## 七、给你的实际路径：先装在 VS Code 里

**这是投入产出比最高的做法。**

1. VS Code 装扩展 **Vim**（作者 vscodevim）
2. 重开 VS Code，你现在可以在编辑器里用 Vim 操作了
3. **保留 `Ctrl+C`/`Ctrl+V`**（设置里可以关掉 Vim 对剪贴板的接管）

推荐设置（`settings.json`）：

```json
{
    "vim.useSystemClipboard": true,
    "vim.leader": "<space>",
    "vim.hlsearch": true,
    "vim.incsearch": true,
    "vim.easymotion": true
}
```

| 设置 | 作用 |
|---|---|
| `useSystemClipboard` | `yy` 复制的能粘到别的程序（`Ctrl+V` 能出来） |
| `leader` | 把 leader 键设成空格（默认是 `\`，难按） |
| `hlsearch` | 高亮所有匹配 |
| `incsearch` | 输入时就实时跳转 |

**每天用 VS Code 时都用 Vim 模式**，一周后基本操作就变肌肉记忆了。

> **心态**：前 3 天你会觉得变慢了。**这是正常的**，就像换键盘布局。撑过去就是纯收益。

## 八、其他生存技巧

| 命令 | 作用 |
|---|---|
| `:e 文件名` | 打开文件 |
| `:set number` | 显示行号（建议写进配置） |
| `:set paste` | 粘贴模式（从外部粘贴不会自动缩进乱掉） |
| `.` | **重复上一次修改**（超好用） |
| `~` | 切换大小写 |
| `J` | 把下一行接到当前行 |
| `>>` / `<<` | 缩进 / 反缩进 |
| `Ctrl+n` | 插入模式下自动补全 |

**`.` 命令值得单独说**：它重复你上一次的**修改**。

比如你要删 5 个地方：删第一个 → 移到下一个 → `.` → 移到下一个 → `.`。
**Vim 高手很大程度就是会用 `.` 和宏。**

## 🤔 卡住了怎么办

| 症状 | 解法 |
|---|---|
| 删了一堆东西 | `Esc` → `u` 撤销。撤销再撤错了用 `Ctrl+r` 重做 |
| 出不来 | `Esc` 然后 `:q!` |
| 粘贴代码缩进全乱 | `:set paste` 后再粘贴 |
| 忘了在哪个模式 | 按 `Esc` 回普通模式，不会有坏事 |
| VS Code 里 `Ctrl+C` 不管用了 | 设置里 `vim.handleKeys` 可以关掉 Vim 对某些键的接管 |
| 觉得太慢想放弃 | **前 3 天必然慢。** 撑过去就好了 |
